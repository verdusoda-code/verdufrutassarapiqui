# AGENTS.md

This document describes the project for developers and AI agents working on this codebase.

## Project Overview

A Spanish-language B2B wholesale produce website for Verdufrutas Sarapiquí in Costa Rica. The first version includes a searchable and filterable demo catalog, editable cart, customer details and order-message preview. It deliberately has no database connection, authentication, real WhatsApp sending, payments or electronic invoicing. Do not add these integrations without explicit authorization.

### Tech Stack

## Key Concepts

### Product Architecture

`src/domain/catalog.ts` defines the asynchronous `CatalogRepository`; `src/data/demo-catalog.ts` is the current fixture adapter. When persistence is requested, the route loader must call a TanStack Start server function wrapping a server-only repository. Loaders are isomorphic: never import database access or secrets directly into a loader or a client component. The static fixture file is not a persistent database or an admin panel.

`src/domain/order.ts` owns quantity validation, formatting, subtotals, totals, order-message composition and the future `OrderStatus` union. Sales in kilograms allow 0.1 increments, units must be whole numbers, and the upper quantity bound is 10,000. The cart reducer is pure; notifications belong in UI handlers. Repeated product additions combine into a single line.

`src/components/product-card.tsx`, `quantity-input.tsx` and `order-dialog.tsx` separate reusable UI from catalog data. OrderDialog coordinates cart, details and demo confirmation. Customer fields and cart live only in React state and reset on reload. Do not silently persist personal data or claim that orders were submitted. The login action displays an explanatory dialog, not simulated authentication.

Future structured persistence must use Netlify Database and Drizzle with a schema at `db/schema.ts`; uploaded image files belong in Netlify Blobs. Future authentication must use `@netlify/identity`, verified server-side permissions and tenant-scoped queries. Read the relevant platform skills before implementation. `docs/architecture.md` explains the planned expansion; none of those backend features exist yet.

### File-Based Routing

Every file in `src/routes/` is a route:

- `__root.tsx` wraps every page.
- `index.tsx` is `/`.
- `about.tsx` would be `/about`.
- `api.*.ts` files are server API endpoints. See the `tanstack-start-api-routes` skill.

### Theme Variables

Colors and corner radius are CSS variables in `src/styles.css` (`--background`, `--foreground`, `--primary`, `--secondary`, `--muted`, `--accent`, `--destructive`, `--border`, `--radius`, and more), with a second set under `.dark`. Tailwind exposes them as classes such as `bg-primary`, `text-muted-foreground`, and `border-border`.

Set these variables for the product before you build any page. In components, use the variable classes instead of raw colors like `bg-white` or `text-gray-600`, so the whole site changes when a variable changes.

### UI Components

Ready-made components are in `src/components/ui/`. Use them before writing your own, and restyle them through the theme variables or their variants. Add more with `npx shadcn add <name>`. Show a toast by calling `toast()` from `sonner`; the container is already mounted in `__root.tsx`. `TooltipProvider` is mounted there too, so `Tooltip` works anywhere without its own provider.

### Browser Storage

Pages are rendered on the server first, where `window` and `localStorage` don't exist. Read `localStorage` inside `useEffect`, not during render or in a `useState` initializer, or the first render will differ from the server HTML and React will log a hydration error.

## Conventions

- Components: PascalCase. Utilities and hooks: camelCase. Route files: kebab-case.
- Import from `src` with the `@/` alias.
- TypeScript fails on unused locals and parameters, so remove what you don't use.
- Use React hooks for state.
- Write public copy in Spanish for Costa Rica and distinguish demo data from real operations.
- Keep the UI wholesale-oriented; do not add retail promotions, payment flows or fabricated contact information.
- Use `src/lib/images.ts` to serve local photography through Netlify Image CDN with responsive widths.
- Preserve keyboard navigation, Radix dialog focus management, accessible labels and reduced-motion support.
- Main visual styles use the CSS variables in `src/styles.css`, with Manrope headings and DM Sans body text.
- The generated assets are included source files; regenerating them consumes credits and overwrites images, so do not run the generation script unless image changes are requested.

## Application Name

Set the product's name and description in `src/routes/__root.tsx`:

- `siteName` is the page title and the title shown when the link is shared.
- `siteDescription` is the meta description and the description shown when the link is shared.

The product name, finished description and Spanish document language are already configured. Do not revert to template branding or add an `og:image`; the platform supplies the share image.
